# FileNest — نسخة السيرفر بدون إنترنت (ويندوز)

نسخة كاملة من الموقع تعمل على كمبيوتر ويندوز واحد داخل الشبكة المحلية، بدون إنترنت.
الهواتف والحواسيب المتصلة بنفس الواي فاي تفتح الموقع من المتصفح أو من تطبيقات FileNest.

## التشغيل
1. فك ضغط الملف في مجلد ثابت، مثل `C:\FileNestOffline` (ليس داخل مجلد التنزيلات).
2. شغّل `Setup-Firewall.bat` مرة واحدة (يطلب صلاحية المسؤول) حتى تصل الأجهزة الأخرى للسيرفر.
3. شغّل `Start.bat` واترك نافذته مفتوحة. أول تشغيل ينشئ قاعدة البيانات ويأخذ دقيقة تقريباً.
4. النافذة تعرض عنوان السيرفر على الشبكة، مثل `http://192.168.1.20`.

أول دخول: `admin@filenest.test` وكلمة المرور `password` — غيّرها مباشرة من الحساب.

## الإيقاف
أغلق نافذة Start أو شغّل `Stop.bat` (يوقف كل شيء ويغلق قاعدة البيانات بأمان).

## التطبيقات
- صفحة `http://<عنوان السيرفر>/apps/` فيها تطبيقات ويندوز وأندرويد وآيفون.
- داخل التطبيق: «إعدادات الخادم» ← «عنوان الشبكة المحلية» = عنوان السيرفر أعلاه.
  وضع «تلقائي» يستخدم السيرفر المحلي إذا كان متاحاً، وإلا الاستضافة.

## الإعدادات (`config.txt`)
- `HTTP_PORT`: منفذ الموقع (80). غيّره إلى 8080 إذا كان برنامج آخر (XAMPP، IIS) يستخدم 80.
- `PHP_WORKERS`: عدد الطلبات في نفس الوقت (8). زِده إذا كان المستخدمون كثيرين.
- `SERVER_IP`: اتركه فارغاً لاكتشاف عنوان الجهاز تلقائياً.
بعد التعديل: `Stop.bat` ثم `Start.bat`.

## أين البيانات
- قاعدة البيانات: `data\mysql` (منفذ 3308 على هذا الجهاز فقط).
- الملفات المرفوعة: `app\storage\app\filemanager`.
للتحديث: أوقف السيرفر، وفك ضغط النسخة الجديدة فوق نفس المجلد (البيانات تبقى)، ثم شغّل `Start.bat`.
خذ نسخة من هذين المجلدين قبل أي تحديث.
