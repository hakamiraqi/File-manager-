# نظام الامتحانات الإلكترونية

نظام امتحانات مستقل (مستخدمون وقاعدة بيانات ونشر خاص به) مبني بنفس بنية FileNest:
**Laravel 13 + Inertia.js (Vue 3) + MySQL**، بواجهة عربية/إنكليزية واتجاه RTL/LTR.

- النسخة التجريبية: https://exams.azoclinic.duckdns.org (تُنشر تلقائياً عند الدفع إلى فرع `exams`).
- الدراسة والتصميم: «دراسة أنظمة الامتحانات الإلكترونية» في Claude Docs.

## ما يعمل الآن (المرحلة الأولى)
- **9 أنماط أسئلة:** اختيار من متعدد بإجابة واحدة أو عدة إجابات (درجة جزئية)، صح/خطأ، إجابة قصيرة
  (تتجاهل الهمزات والتشكيل)، رقمي بهامش خطأ ويقبل الأرقام العربية ١٢٣ و٫، مطابقة، ترتيب، مقالي (تصحيح يدوي)، ونص توضيحي.
- **نصوص بعدة لغات:** لكل امتحان لغاته (العربية، الإنكليزية، الكردية)، وكل سؤال وخيار يُكتب بكل لغة،
  والاتجاه تلقائي أو محدد لكل امتحان.
- **أداء الامتحان:** مؤقت محسوب في الخادم، حفظ تلقائي لكل إجابة، «راجع لاحقاً»، تسليم تلقائي عند انتهاء الوقت،
  خلط الأسئلة والخيارات، كلمة مرور للامتحان، نافذة فتح وإغلاق، عدة محاولات وطريقة احتساب الدرجة.
- **المراقبة:** تسجيل مغادرة الصفحة وترك النافذة واللصق وتغيّر عنوان IP لكل محاولة.
- **التسهيلات:** وقت إضافي دائم لطالب (×1.25 / ×1.5 / ×2) من لوحة الإدارة، واستثناءات لكل امتحان
  (دقائق إضافية تصل حتى لمحاولة جارية، إغلاق متأخر، محاولات أكثر).
- **النتائج:** ملخص، تحليل سهولة كل سؤال، تصحيح المقالي مع ملاحظة، إعادة التصحيح بعد تعديل مفتاح، تصدير Excel (CSV).
- **الصلاحيات:** المشرف، والأستاذ (`is_examiner` من نافذة المستخدم)، والطالب (أي حساب مفعّل).

## الدخول الأول
`admin@exams.test` — كلمة المرور سُلّمت بشكل خاص (المستودع عام، فيه بصمتها فقط في `deploy/vps/admin-password.hash`).
غيّرها من «الملف الشخصي» بعد أول دخول، ثم أنشئ حسابات الأساتذة والطلاب من لوحة الإدارة.

## التطوير
```
composer install && npm ci && npm run build
cp .env.example .env && php artisan key:generate && php artisan migrate --seed
php artisan test tests/Feature/Exams
```

## ملاحظة
هذا الفرع بدأ من نسخة من FileNest، وما زالت فيه وحدات FileNest (الملفات، المكتبة، الرسائل…) مخفية عن القائمة.
تُزال تدريجياً في المراحل التالية حتى يبقى نظام الامتحانات وحده.
