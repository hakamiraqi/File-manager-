# استبيان جاهزية المراكز الصحية لتقديم خدمات تنظيم الأسرة

نسخة على الإنترنت من استمارة Excel (`app/template.xlsx`)، بنفس تصميمها وألوانها.

- **الموقع:** https://survey.azoclinic.duckdns.org
- **الدخول:** مفتوح بلا حساب. أي شخص معه الرابط يضيف استمارة لمركزه ويعدّل أي استمارة.
- **الحفظ:** كل تغيير يُحفظ تلقائياً. إذا عدّل شخصان الاستمارة نفسها في الوقت نفسه، تُدمج تعديلاتهما خانةً بخانة.
- **الأمان من الأخطاء:** لكل استمارة «سجل التعديلات»، ويمكن إرجاعها إلى أي نسخة سابقة. المحذوفة تذهب إلى «المحذوفات» وتُسترجع منها.
- **Excel:** كل استمارة تُنزَّل على شكل ملف Excel الأصلي نفسه، معبّأ. وتنزيل الكل يعطي ورقة «الملخص» (صف لكل مركز)، ثم ورقة لكل مركز.
- **تعديل الأسئلة:** عدّل `app/template.xlsx` (بنفس ترتيب الأقسام والأعمدة) وادفعه. الموقع يقرأ الأسئلة منه، فلا حاجة لتعديل الكود.
- **النسخ الاحتياطية:** نسخة يومية داخل الحاوية (آخر 30 يوماً)، ونسخة قبل كل تحديث في `~/survey-backups` على السيرفر (آخر 20).

## التشغيل محلياً

```sh
pip install openpyxl
python3 app/server.py          # http://localhost:8080
python3 -m unittest discover -s tests
```

## النشر

يُنشر تلقائياً عند الدفع إلى الفرع `survey` (`.github/workflows/deploy-survey.yml`): اختبارات ← نسخ إلى `~/survey` على السيرفر ← `deploy/deploy.sh` (حاوية `survey-web` خلف Caddy المشترك).
